# SAVO release readiness — checklist and evidence

Audit date: **27 November 2026**. Scope: the release checklist supplied by the
owner, checked against the repository, the live site (`https://savo.freebuff.page`),
the live Supabase project (`lbowjunrhljkntchrmjr`) and the dependency tree.

Status vocabulary:

- **DONE** — verified this pass, with the command or query named.
- **FIXED** — a defect or gap found this pass and closed; evidence given.
- **OWNER** — impossible to do from the repository: needs your Play Console,
  your Google account, a lawyer, or a physical device.
- **BLOCKED** — cannot be verified from here at all (no Android project exists).

Nothing in this file claims Play approval, legal compliance, or that the app has
been installed on a phone. Where an item is not verifiable, it says so.

### The five things that actually block a Play submission today

1. **There is no Android build.** No wrapper, no AAB, no signing. Everything in
   section 1 depends on producing one, at API 36, with one package ID.
2. **Two package IDs are declared** in `assetlinks.json`. Pick one.
3. **Business registration and ODPC numbers are `TODO_`** in the legal config.
4. **Payment model for Market** is undefined in writing (who holds funds).
5. **Kenyan legal review** of terms, privacy and the marketplace model.

Everything else in this checklist is either done, done-with-a-caveat, or a
procedure that only the operator can own.
